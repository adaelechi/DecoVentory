# DecoVentory Documentation

Welcome to the official documentation for **DecoVentory**, a comprehensive inventory management system designed for decoration units.

## 🌟 Overview

DecoVentory is a full-stack web application that helps organizations track their decoration materials, manage chapel usage, record event decorations, and handle external borrowing with ease. It features a robust backend API and multiple frontend modules tailored for different user needs.
