# Admin Manual

This guide is intended for Executives and Administrators of the DecoVentory system.

## 🔐 Logging In
1. Navigate to the **Admin** section from the sidebar.
2. Enter the **Executive Passcode**.
3. If successful, you will be redirected to the Admin Dashboard.

## 📦 Managing Inventory

### Adding a New Item
1. Go to the **Add New Resource** page.
2. Fill in the name, category, and total quantity.
3. (Optional) Provide a URL for the item image.
4. Click **Save Resource**.

### Editing/Deleting Items
1. From the Admin Dashboard, locate the **Manage Resources** section.
2. Click **Edit** on an item to change its properties or location.
3. Click **Delete** to permanently remove an item from the inventory.

## 📋 Handling Rental Requests
1. When a user submits a request via the "Rent Materials" page, it appears in the **Pending Rent Material Requests** section.
2. Review the items and dates.
3. Change the status to **Approved** or **Rejected**.

## 🎭 Recording Events
1. Use the **Manage Decorations** section to record new events.
2. Specify the materials used. **Note:** This will automatically reduce the available quantity in the inventory.
3. When the event is over, mark it as **Returned**. If items were lost or damaged, record them to update the total inventory counts.

## 📜 Reviewing Logs
The **Recent Activity Logs** section provides a timestamped history of every action. Use this to audit inventory movements or identify who borrowed specific items.

## 🛡️ Updating Security
You can update the passcodes for both Executive and Admin levels in the **Security & Access Control** section at the bottom of the Admin Dashboard.
